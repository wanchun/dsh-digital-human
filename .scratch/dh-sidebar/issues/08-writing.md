# 08 · 人设与技能写作规范

Type: task
Status: open

## Question

把散在对话里的写作规则固化成文件，供之后所有数字人遵守：

- 人设 ≤600 字，四段式：身份一句 / 输入 / 回执 / 遇到这些情况（表格）
- 人设可点名技能，但必须写依赖：`依赖技能：<名字>（用它做<哪一步>）`
- playbook ≤1.5K：步骤 + 完成判据；细节进 `references/`
- 给人看的文档遵循 ASD-STE100 的 80%
- **上下文预算**：每轮只读当前需求摘要 + 当次任务所需文件；节点证据只读结论段，要细节按路径取
- **技能库搬迁**：插件技能库 `<home>/skills` 的技能搬到全局 `~/.agents/skills`，记录只做勾选白名单（影子屏蔽已实现）

产出：一份 `docs/agents/writing.md`（或并入 GLOSSARY 的「写作规则」），并把五份人设按模板校对一遍。
