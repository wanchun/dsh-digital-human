# 05 · 技能改为全局库 + 按记录勾选

Type: grilling
Status: resolved

## Question

用户定调：

1. **去掉插件的自定义技能空间**，技能统一放到全局技能库（`~/.agents/skills`）。
2. 记录的配置里**能读到全局技能清单**，逐个勾选启用；**没勾选就不能用**。
3. 勾选了才可用。
4. 人设**可以指定技能**，但必须写清依赖关系（"依赖技能 pm-intake 的建档步骤"），不能只留一个名字。

要定：

- **白名单怎么落地**：全局技能本来就对每个会话可见，插件要把"没勾的"藏起来，靠什么机制？（现有做法是按记录 `ctx.skills.register` 只挂勾选的，那全局目录里的技能会不会同时可见？需要确认，否则白名单形同虚设。）
- **插件技能库还留不留**：直接删掉、还是保留成"全局库的镜像"。
- **勾选面板的数据源**：读 `~/.agents/skills/*/SKILL.md` 的 name/description 列表。
- **人设写依赖的格式**：一行 `依赖技能：<name>（用它做 <步骤>）`。
