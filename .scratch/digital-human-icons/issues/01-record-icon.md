# 01: 记录带图标：字段、校验、存取、注册工具、打包

**What to build:** 一条数字人记录可以携带可选的图标（data URI）。通过注册工具设置后，它落在配置文件里，列表与详情能读回；非法格式或超限被明确拒绝，空字符串清除；导入导出保留。没有图标的记录与今天完全一样。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 合法的 png/jpeg/webp/svg+xml base64 data URI 被接受并持久化
- [ ] 非法前缀、非 base64、超过 64KB 的图标被拒绝，报错说明原因
- [ ] 空字符串或未设置表示没有图标，配置里不写该字段
- [ ] 读写往返后图标不变；旧记录缺字段视为空
- [ ] 注册工具的 create/update 接受图标，空字符串清除
- [ ] 导出的包携带图标，导入后读回一致
