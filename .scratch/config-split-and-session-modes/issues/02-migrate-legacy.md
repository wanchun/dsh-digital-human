# 02: 迁移命令（旧单文件 → 目录）

**What to build:** 一条可预演、可重复执行的迁移命令，把旧的单文件注册表逐条转成目录。执行时先备份，再逐条写入，随后从目录重新合成并与旧记录逐字段比对；任何一条不一致就中止且不动原文件。宿主正在运行时拒绝执行。

**Blocked by:** 01（目录记录的读写）

**Status:** ready-for-agent

- [ ] 预演只列出将迁移的记录和目标目录，不写任何文件
- [ ] 宿主运行时命令拒绝执行，并说明原因
- [ ] 正式执行前生成带时间戳的旧文件备份
- [ ] 逐条写人设与配置，随后从目录合成并与旧记录逐字段比对
- [ ] 任一字段不一致时中止，旧文件与已写目录可回滚
- [ ] 全部校验通过后才删除旧单文件
- [ ] 重复执行时识别已完成并直接退出
- [ ] 迁移逻辑位于存储层，命令只做参数解析与运行状态检查
- [ ] 迁移读取旧文件是独立路径，不是正常启动路径的回退
