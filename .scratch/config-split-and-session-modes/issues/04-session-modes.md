# 04: 会话模式与标题

**What to build:** 记录新增"会话模式"：按线程（默认）或共享一条。共享一条的数字人只拥有一条长期会话，所有派活进入同一条会话并在当前回合结束后排队执行；会话建立时用记录名命名。按线程维持现有行为。没有绑定机器人的记录也能给自己的会话改名。注册工具和设置页都能设置这个字段。

**Blocked by:** 01（字段落在配置文件中）

**Status:** ready-for-agent

- [ ] 会话模式写入配置文件，默认"按线程"
- [ ] 注册工具可设置该字段，设置页有对应下拉
- [ ] 共享一条：两个不同线程标识的派活只落一条会话
- [ ] 共享一条：第二个任务以排队方式处理，不打断正在执行的回合
- [ ] 按线程：两个线程标识仍是两条会话，插话方式不变
- [ ] 共享一条：会话建立时标题就是记录名
- [ ] 共享一条：不带地址的回执仍回到派活的那条会话
- [ ] 状态、消息、停止都能定位到常驻会话
- [ ] 没有机器人的记录可以调用改名工具并生效
