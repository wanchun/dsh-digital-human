# 05: 真实数据迁移与上线

**What to build:** 用真实注册表完成一次迁移并上线：停宿主、备份、预演、迁移、重启；两个现有数字人字段与行为不变；新建一个共享一条的自测数字人，跑通一次派活、排队与回执。回滚步骤留档。

**Blocked by:** 02（迁移命令）、03（导入导出）、04（会话模式）

**Status:** ready-for-agent

- [ ] 停宿主后执行预演，输出与真实记录数一致
- [ ] 正式迁移后旧单文件被备份并删除，目录完整
- [ ] 重启后 PM 与研发助手可正常列出、查看、编辑
- [ ] 两者的人设正文、配置字段与迁移前逐项一致
- [ ] 新建一个共享一条的数字人，两条派活只落一条会话且第二条排队
- [ ] 该数字人的回执回到派活会话，状态与消息可读
- [ ] 回滚步骤在一份副本上验证通过并记录
