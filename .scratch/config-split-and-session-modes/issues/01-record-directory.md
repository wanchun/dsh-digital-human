# 01: 目录记录：读、写、删

**What to build:** 通过注册工具创建一条数字人记录时，落盘是一个目录：人设文件（元数据 + 正文）和配置文件。列表、详情、设置页保存都能读回这条记录；修改只重写这一条；删除只删人设与配置两个文件，记忆和会话记录保留。人设里指向注册表的那句话改成指向目录。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 创建后目录内出现人设文件与配置文件，字段与人设正文完整
- [ ] 列表、详情、按名称解析都能读回同一条记录，字段逐项一致
- [ ] 设置页保存走原有接口，只更新该记录的两个文件
- [ ] 更新保留创建时间并刷新更新时间
- [ ] 删除只移除人设与配置，记忆、会话索引、对话记录都保留
- [ ] 人设或配置损坏时报错并指出记录 id；未知字段被忽略
- [ ] 人设中的注册表位置指向数字人目录
- [ ] 种子记录首次使用时也落成目录
- [ ] 正常读取路径不回退到旧的单文件格式
