# 03: 导入导出适配目录

**What to build:** 导出一个或多个数字人时按目录打包（人设、配置、可选记忆、指定技能）；导入时同时接受新目录包和旧格式包，导入后记录可正常读取与使用。

**Blocked by:** 01（目录记录的读写）

**Status:** ready-for-agent

- [ ] 导出的包内每条记录是人设与配置文件，不再包含旧单文件注册表
- [ ] 可选包含记忆与技能，未选择的技能不进入包
- [ ] 导入新包后记录可读，字段与人设正文一致
- [ ] 导入旧格式包后记录转成目录并可读
- [ ] 导出 → 导入往返后记录逐字段一致
- [ ] 包内条目缺失或损坏时报错，不产生半条记录
