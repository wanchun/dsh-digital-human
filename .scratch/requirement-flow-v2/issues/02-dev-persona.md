# 02: 研发助手链路到自测

**What to build:** 研发助手的节点链改为 A–F；D 部署成功后派 E 自测给自测助手并轮询；自测通过才进 F 冒烟；失败进修复循环；总表只写执行侧两列；`peers` 加自测助手。

**Blocked by:** 01（技能先定 E/F）

**Status:** ready-for-agent

- [ ] persona 中节点链为 A–F，D 成功后明确“派 E 自测”
- [ ] 派单只给指针与事实（版本目录、params、PR/commit、部署包、环境主机、验收、允许操作、报告路径），不写自测范围
- [ ] 1 分钟轮询 status，上限 30 分钟；超时标阻塞并附证据
- [ ] 自测不通过进现有修复循环，重新部署后重跑，≤3 轮
- [ ] 自测通过才触发 F 冒烟；极速/纯前端跳过时记录理由
- [ ] 总表只写 `执行状态/当前节点`，不写 `建档状态/备注`
- [ ] `peers` 增加 `qa-assistant`
